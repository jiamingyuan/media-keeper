## 本版变化

- **Loot Drop 来源**：专门展开分析卡片的 data-full-text，保留概况表、重建折叠正文、技术条目及相关案例链接；缺失结构时明确失败，不把预览当全文。Agent 查证中国公司的中文名，报告统一命名为“{公司名称} Loot Drop 分析”，按正文深度与内容覆盖要求撰写。
- **双链接与恢复**：此来源保留原文的同时创建/核验飞书分析文档，两个链接进入同一记录；已有副本也回读。草稿支持系统临时目录且拒绝越界路径，保留查重、全文读取确认、失败不入库、重试复用与明确更新要求。完整处理与独立分析按内容/授权范围区分，不承诺用换词无损替代外部原文。
- **摘要质量**：规则面向未读者说明对象、问题和主要观点，解释必要术语，保留限制，不靠堆名词压缩；仍最多 400 个 Unicode 字符。历史上 19 条摘要已改写，属于资料库运行数据，不随 Git 导出。
- **部署方式**：新增 package:deploy 打包工具与 deploy/start.sh，使用已有 node-nginx 镜像运行独立 media-keeper 容器；移除旧自定义 Dockerfile、Compose 和 .dockerignore。保留只读挂载、API 配置隔离、进程联动退出与健康检查；本次 Git 发布不执行容器替换或镜像构建。
- **正式说明与项目记忆**：补充 architecture，按含义整理 brief/rules/index；保留 V0.1/V0.2 原始迭代记录，V0.4 发布后实测历史继续在原位置引用。AGENTS.md 仅保存用户指定的两条镜像/容器操作规则，不复制为 pjkp 原则。
- **版本一致性**：全部六个本地 package 清单、内部依赖、锁文件与 Skill 元数据统一为 0.5.0；独立 Skill 构建与全局安装同步。本版没有新增数据库字段或 source_type，没有改动前端产品界面。
