# 摘要的取舍

摘要让用户判断是否值得读全文，不是引言、宣传文案或目录。

- 先找作者真正的结论和内容新增的信息：回答了什么、发现了什么、具体如何做。必要时保留决定结论的关键数字/比较、前提和限制。
- 覆盖全文的主要信息，包括正文后半段的结论；长文可逐节做临时笔记，再综合成一个摘要，去掉重复。
- 长度随信息量变化，**上限400个Unicode字符（含标点与空白）**，没有下限，十几个字也可以。脚本超限会拒绝，不会截断；应重新压缩、保持完整句意。
- 主体只有几句话时，一句摘要通常就足够。语言切换、导航链接、页面排版及重复译文不是正文的新信息，不为展示“读过网页”而写入摘要；只有它们本身就是收藏主题时才保留。
- 用紧凑自然段，必要时少量并列要点。不强制“背景/方法/结论”等模板，不写“本文介绍了……值得阅读”等无信息句，不抄第一段。
- 区分来源的主张、证据与推测，不把相关性说成因果，不凭常识补原文没有的细节；商业宣传及证据不足的结论要保留其限定。
- 视频摘要基于完整字幕/转写；论文摘要基于全文，不仅改写论文自带 abstract。

提交前自查：读者能否说出全文最重要的结论？是否保留影响理解的条件/限制？哪些词删掉也不损失信息？是否引入了原文没有的判断？
